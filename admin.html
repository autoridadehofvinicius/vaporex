O painel publica as mudanças no GitHub. Para isso, cole um token que dá acesso somente ao repositório da loja:

  1. Abra github.com → novo token
  2. Em Repository access, escolha Only select repositories e marque só vaporex
  3. Em Permissions → Contents, escolha Read and write
  4. Gere e cole aqui embaixo
